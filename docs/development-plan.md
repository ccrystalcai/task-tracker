# 开发计划

## 总体原则

1. **小步快跑**：每个阶段产出可用的功能增量，不做"一口气做完"
2. **先骨架后血肉**：先搭结构跑通流程，再加细节和美化
3. **每阶段验收**：完成一个阶段后确认效果，再进入下一阶段
4. **数据安全优先**：第一时间实现数据导出，保护用户数据

---

## Phase 1：项目骨架搭建（预计 2-3 天）

**目标**：项目能跑起来，有页面框架和基础数据能力

| 任务 | 产出 |
|------|------|
| 初始化 Vite + React + TS 项目 | 项目能 `npm run dev` 启动 |
| 配置 Tailwind CSS + 主题 CSS 变量 | 主题切换基础 |
| 配置 React Router + 6 个页面占位 | 页面之间可跳转 |
| 配置 Dexie.js + 定义数据库 Schema | 数据库能读写 |
| 搭建布局组件（Sidebar + Header + 内容区） | 统一的页面框架 |
| 实现主题切换（至少 Daylight + Midnight） | 设置页能切换主题 |

**验收标准**：6 个空白页面可切换，主题可切换，数据可存入 IndexedDB

---

## Phase 2：目标与任务 CRUD（预计 2-3 天）

**目标**：能创建目标、创建任务，数据持久化

| 任务 | 产出 |
|------|------|
| 目标创建/编辑/删除表单 | 目标规划页基础功能 |
| 任务创建/编辑/删除表单（含优先级、时长） | 任务属性能完整录入 |
| 任务与目标的关联关系 | 任务可归属到目标 |
| 预设模板数据 + 一键导入 | 模板功能 |
| Zustand store 集成 | 数据流贯通 |
| 数据导出 JSON 功能 | 安全备份能力 |

**验收标准**：能创建目标 → 手动拆解子任务 → 数据刷新不丢失 → 能导出 JSON

---

## Phase 3：今日看板（预计 2-3 天）

**目标**：今日任务看板是使用频率最高的页面，需要做好

| 任务 | 产出 |
|------|------|
| 今日任务列表（自动筛选到期日 = 今天） | 核心视图 |
| 任务完成勾选 + 动画 | 核心交互 |
| 四象限视图（2x2 网格） | 优先级可视化 |
| 手动快速添加任务 | 临时任务入口 |
| 鼓励语弹窗（完成全部任务时） | 激励系统 V1 |
| 浏览器通知提醒（Notification API） | 基础提醒 |

**验收标准**：今日任务可见、可勾选完成、四象限正常展示、有鼓励弹窗

---

## Phase 4：每日小结（预计 2 天）

**目标**：完成一天后的复盘闭环

| 任务 | 产出 |
|------|------|
| "完成一天"按钮 + 自动汇总 | 小结生成 |
| 逐任务反思输入 | 反思记录 |
| 任务星级打分（1-5） | 评分系统 |
| 图片上传（存 IndexedDB Blob） | 截图功能 |
| 当天整体小结输入 | 总览反思 |
| 小结数据存储到 daily_summaries 表 | 数据持久化 |

**验收标准**：点"完成一天"→ 弹出小结 → 可写反思/打分/传图 → 保存成功

---

## Phase 5：分析统计（预计 2-3 天）

**目标**：可视化了解执行情况

| 任务 | 产出 |
|------|------|
| 热力图组件（参考 GitHub 贡献图） | 打卡可视化 |
| 月历视图 + 任务标记 | 月历组件 |
| 完成率折线图（Recharts） | 趋势图表 |
| 目标进度条 + 里程碑时间线 | 大局视图 |
| 统计页数据汇总 | 总览面板 |

**验收标准**：热力图正常渲染、月历可切换月份、图表数据正确

---

## Phase 6：反思日记（预计 2 天）

**目标**：每日心情记录和状态追踪

| 任务 | 产出 |
|------|------|
| 日记列表页（按日期） | 日记总览 |
| 心情选择器（emoji 5 档） | 心情记录 |
| 日记编辑器 | 文字输入 |
| 优化建议生成（规则引擎） | 自动建议 |
| 与任务完成数据关联展示 | 当天任务 + 心情同屏 |

**验收标准**：能写日记、选心情、看到优化建议

---

## Phase 7：全局搜索（预计 1-2 天）

**目标**：快速找到任何任务及其历史

| 任务 | 产出 |
|------|------|
| fuse.js 集成 + 模糊搜索 | 搜索输入框 |
| 搜索结果列表 | 匹配结果展示 |
| 任务详情面板（月历+评分+反思+截图） | 搜索结果详情 |
| 从搜索结果跳转到对应页面 | 快速导航 |

**验收标准**：输入关键词 → 匹配任务 → 查看详情 → 可跳转

---

## Phase 8：Google 日历 + 设置完善（预计 2 天）

**目标**：日历同步和设置完善

| 任务 | 产出 |
|------|------|
| Google OAuth 登录流程 | 授权页面 |
| 任务同步到 Google Calendar | 自动创建日历事件 |
| 提醒时间设置 | 设置页面 |
| 数据导入功能 | JSON 导入恢复 |
| UI 细节打磨 + 动画优化 | 整体 polish |

**验收标准**：授权后可同步任务到 Google Calendar，设置项全部可用
