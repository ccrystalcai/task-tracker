# 需求规格文档

## 项目概述

**项目名称**：TaskTracker（待定）
**产品形态**：纯网页应用，浏览器打开即用
**目标用户**：希望提升执行力的个人用户

---

## 核心需求

### 1. 目标规划模块

> **目标与任务的关系**：目标一定是由若干任务组成的（先有目标 → 拆解出任务），但任务不一定要归属于某个目标，用户可以直接创建独立任务。

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| R1.1 | 创建目标 | 输入目标名称、描述、截止日期 | P0 |
| R1.2 | 手动拆解子任务 | 为目标手动创建子任务，设置预估时长、截止日期 | P0 |
| R1.3 | 预设模板 | 提供常用目标模板（学编程、健身、学语言等），一键导入目标+任务 | P1 |
| R1.4 | 目标进度 | 展示目标完成百分比和剩余天数，基于关联任务完成率计算 | P0 |

### 2. 今日看板 / 任务管理模块

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| R2.1 | 今日任务列表 | 展示当天所有待完成任务（含独立任务 + 目标关联任务） | P0 |
| R2.2 | 任务完成勾选 | 点击打勾标记完成 | P0 |
| R2.3 | 四象限视图 | 按紧急/重要四象限展示任务 | P1 |
| R2.4 | 手动添加任务 | 快速添加临时/独立任务（不需要关联目标） | P0 |
| R2.5 | 完成一天按钮 | 点击后生成当天小结 | P0 |
| R2.6 | 激励弹窗 | 懈怠时弹出鼓励语，完成好时弹出表扬 | P1 |
| R2.7 | 单任务提醒 | 每个任务可独立设置提醒时间，到点浏览器通知 | P1 |
| R2.8 | 任务标签 | 任务支持打自定义标签（如 #学习 #工作 #健康），可按标签分类查看 | P1 |
| R2.9 | 标签管理 | 自定义创建/编辑/删除标签，支持标签颜色 | P1 |

### 3. 每日小结模块

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| R3.1 | 自动小结 | 汇总当天完成任务数、总时长、未完成任务 | P0 |
| R3.2 | 逐任务反思 | 为每项已完成任务写反思 | P1 |
| R3.3 | 任务打分 | 为完成的任务打分（1-5星） | P2 |
| R3.4 | 图片上传 | 为任务上传相关截图/照片 | P2 |
| R3.5 | 当天整体小结 | 写一段整体总结 | P1 |

### 4. 分析统计模块

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| R4.1 | 打卡热力图 | 类似 GitHub 贡献图，展示任务完成情况 | P1 |
| R4.2 | 月历视图 | 按月查看任务完成记录 | P1 |
| R4.3 | 完成率图表 | 折线图/柱状图展示完成率趋势 | P1 |
| R4.4 | 时间节点 | 显示任务关键里程碑和时间线 | P2 |

### 5. 反思日记模块

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| R5.1 | 日记列表 | 按日期查看所有日记 | P1 |
| R5.2 | 心情记录 | 选择当天的情绪状态（😊 😐 😔 等） | P1 |
| R5.3 | 状态分析 | 根据完成情况和心情输出状态总结 | P2 |
| R5.4 | 优化建议 | 自动给出现阶段调整建议 | P2 |

### 6. 全局搜索模块

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| R6.1 | 模糊搜索 | 输入关键词匹配任务名称 | P1 |
| R6.2 | 搜索结果展示 | 显示任务详情、月历热力图、历史打分、反思、截图 | P1 |
| R6.3 | 快速跳转 | 从搜索结果跳转到对应任务详情 | P2 |

### 7. 设置模块

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| R7.1 | 主题切换 | 多套主题可选（浅色/深色/暖色等） | P1 |
| R7.2 | 提醒时间设置 | 设置每日任务提醒时间 | P1 |
| R7.3 | Google 日历绑定 | OAuth 授权同步任务到 Google Calendar | P2 |
| R7.4 | 数据导出/导入 | JSON 格式导出备份，支持导入恢复 | P1 |
| R7.5 | 数据清除 | 清除所有本地数据 | P2 |

---

## 非功能需求

- **离线可用**：纯本地存储，无需网络即可使用（除 Google 同步外）
- **响应式**：适配桌面端为主，平板可用
- **性能**：页面切换流畅，数据加载 < 200ms
- **数据安全**：提供导出备份功能，防止浏览器数据丢失

---

## 优先级说明

| 级别 | 含义 |
|------|------|
| P0 | 核心功能，第一阶段必须完成 |
| P1 | 重要功能，第二阶段完成 |
| P2 | 增强功能，第三阶段完成 |
